# Portofolio-Statis-Simple

Website portofolio statis yang minimalis, elegan, dan responsif. Didesain untuk kemudahan penggunaan dan tampilan yang bersih.

## Fitur
- **Desain Minimalis**: Fokus pada konten dan tipografi yang elegan.
- **Animasi Scroll**: Menggunakan Intersection Observer API untuk gerakan yang halus.
- **Responsif**: Tampilan optimal di berbagai perangkat (Mobile, Tablet, Desktop).
- **Siap Deploy**: Struktur file yang sederhana untuk GitHub Pages.

## Cara Menambahkan Karya Anda
1. Buka file `index.html`.
2. Cari bagian `<section id="projects">`.
3. Di dalam `<div class="projects-grid">`, Anda akan menemukan blok kode dengan class `project-card`.
4. Salin (copy) satu blok `project-card` dan tempel (paste) di bawahnya.
5. Ganti judul, deskripsi, dan link sesuai dengan karya Anda.
6. Untuk menambahkan gambar, ganti isi dari `<div class="project-image">` dengan tag `<img>`.
